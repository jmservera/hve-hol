Cómo ejecutarlo

Los mismos entregables, con el entorno de ejecución que elijáis

En esta páginaCadena de herramientas MicrosoftReferencia rápidaVersiones de la configuración

HVE Core

Las herramientas que dirigís vosotros

  • RPI Agent o las cuatro habilidades de fase: investigación, planificación, implementación y revisión
  • Agentes especializados en requisitos, decisiones de arquitectura, planificación de seguridad e IA responsable, un coach de Design Thinking y un Backlog Manager para los recorridos de Azure DevOps y GitHub
  • Vosotros aprobáis cada fase

Ideal paraaprender el método, un solo equipo y control estricto

HVE-Squad

Experimental

Orquestación sobre la misma base

  • Una petición: un coordinador la deriva a un conjunto de agentes de HVE Core
  • Modos de autonomía: interactivo (predeterminado) · autónomo · piloto automático
  • Tope de coste, registro de decisiones y registro de consumo
  • Siempre se detiene antes de cualquier acción irreversible: despliegue, push, merge o cambio de esquema

Ideal paratrabajo con varios roles, trazabilidad de auditoría y visibilidad del coste por ejecución

Vuestro propio orquestador

Traed lo que ya utilizáis

  • Es bienvenido si muestra las mismas evidencias: investigación y plan antes de implementar, un registro de revisión y un registro de decisiones
  • Evaluado con el mismo cuadro de evaluación común

HVE es el modelo operativo. Las herramientas son opcionales; las evidencias, no.

Consejos

  • HVE-Squad es un proyecto de la comunidad basado en HVE Core, en fase de colaboración con socios de diseño.

Recorridos del taller centrados en Microsoft

Entrega en Azure DevOps o GitHub; evidencias de Microsoft 365

NecesidadProductos MicrosoftLímite
Planificar el trabajoAzure DevOps (ADO): elementos de trabajo de Azure Boards o GitHub IssuesPrimero, lectura; aprobar las escrituras en el backlog y el proyecto/repositorio de destino

Work IQ es opcional, no se da por disponible

Utilizad una conexión documentada de Copilot CLI o un cliente con MCP autorizado para el taller. Antes de recuperar información real, confirmad el inicio de sesión/consentimiento, las directivas del inquilino y las herramientas de lectura disponibles. La versión preliminar de retrieve puede requerir además facturación de Work IQ API y una directiva de gasto de Copilot Credits. No cambiéis las directivas del inquilino durante un ejercicio. Si no está disponible o se deniega el acceso, detened esa recuperación y usad las evidencias iniciales ficticias u otro conjunto de fuentes autorizado; registrad la limitación y nunca inventéis un resultado de una consulta real.

Referencia rápida

Puntos de entrada y ubicación de las evidencias

HVE Core

VS Code con GitHub Copilot Chat o Copilot CLI

  • Selector de agentes → RPI Agent: describid la tarea; manual por defecto, totalmente automático solo si se solicita
  • Habilidades de fase → /rpi-research · /rpi-plan · /rpi-implement · /rpi-review
  • Antes de actuar → /rpi-challenger (hacer visibles los supuestos) · /rpi-walkthrough (explicar el código antes de cambiarlo)
  • Agentes especializados → BRD Builder · PRD Builder · ADR Creator · Security Planner · RAI Planner · DT Coach · Backlog Manager · Code Review
  • Habilidades de backlog → /backlog-plan (solo lectura) · /backlog-execute (escribe en el sistema de seguimiento)
  • Cread los vuestros → /hve-builder

HVE-Squad

  • /squad init → revisad y confirmad el equipo propuesto (sin piloto automático durante la configuración)
  • /squad request="…" → interactivo por defecto; añadid mode=autonomous o mode=autopilot
  • añadid cost-ceiling=<USD> → previsión de gasto y punto de parada
  • añadid routing=off | ranked | economy | manual → elección de modelo por rol
  • pedid al coordinador que ejecute squad-doctor antes de empezar
  • /squad-governance-report → panel de gobierno
  • Copilot CLI o aplicación: elegid Squad Coordinator y enviad el mismo texto sin /squad

Dónde se guardan las evidencias

.copilot-tracking/
├── research/   ← notas de investigación
├── plans/      ← plan
│               (+ crítica en reviews/plans/)
├── changes/    ← registro de cambios
├── reviews/    ← registros de revisión
└── squad/      ← estado de HVE-Squad
    ├── team.md · routing.md
    ├── decisions.md
    ├── history/
    ├── consumption.md
    └── state.json

La memoria de trabajo no es la fuente de verdad: trasladad las decisiones a ADR, requisitos, documentación y backlog, y mantened .copilot-tracking/ fuera de main.

Consejos

  • HVE Core ya no distribuye archivos de prompts: /rpi se ha retirado; usad RPI Agent y describid la tarea.
  • Utilizad Backlog Manager para el recorrido de Azure DevOps o GitHub; confirmad la organización, el proyecto o el repositorio de destino antes de permitir escrituras.
  • El agente Meeting Analyst es experimental y necesita el servidor Work IQ MCP, que puede no estar disponible en vuestra organización. Las evidencias de reuniones deben seguir siendo opcionales: utilizad extractos ficticios autorizados o las preguntas de PRD Builder si no está habilitada la recuperación real. Las notas de Teams son evidencias, no una aprobación automática de requisitos.
  • En HVE-Squad, utilizad un modelo fijo y potente para el coordinador, no Auto.

Configuración

Versiones fijadas para la jornada

  • HVE Core: registrad la versión de la extensión o del plugin instalada para el taller
  • HVE-Squad: una misma etiqueta de versión fijada para todos (v0.18.1 al redactar esta guía; consultad Releases)
  • APM CLI: exactamente 0.29.0 (0.29.1 y 0.30.0 rompen la instalación de HVE-Squad); el recorrido de VS Code para HVE-Squad lo necesita
  • PowerShell 7+ en todos los portátiles
  • Autenticación en GitHub antes de instalar (gh auth login o GITHUB_TOKEN) para evitar límites de solicitudes
  • No instaléis el plugin oficial de HVE Core junto al par de plugins de HVE-Squad: todos los agentes aparecerían por duplicado
  • Un único modelo fijo para el coordinador en todos los equipos, no Auto

No actualicéis el mismo día

Utilizad las versiones instaladas durante la preparación. HVE Core y HVE-Squad evolucionan rápidamente.
