Intermission C · While Exercise 5 executes · Open lab 3 · Parallel task

What did we ask AI to do that a script could do?

Waiting-time taskOpen lab 3

On this pageBriefHand-in and toolkitTips
Objective

Find the steps that should be deterministic, and make every step the AI keeps verifiable.

Input
The Exercise 5 run: prompts, research, plan and change log, plus the auditor’s log
Best use
Waiting-time task during Ex 5
Roles (suggested)
Architect and quality lead; agent operator supplies the run files

Steps

  1. List every task you asked the agent to do in the Ex 5 run.

  2. Classify each: script alone · AI with a deterministic check · judgement.

  3. For each script candidate, name the tool: lint, codemod, template, schema, CI check or git hook.

  4. For tasks where AI stays, add a fixed step list and a check that fails the run if a step is skipped.

  5. Run one script or check against the Ex 5 artefacts and record what it catches that the agent missed.

Hand in

Tick items as your team hands them in.

Template 2 · Step verifier

StepRequired outputCheck (script)Fails if…

Example: every plan task ID (P01-T01…) appears in the change log and review record

Run it with

The Ex 5 artefacts in .copilot-tracking/ (research, plans, changes, reviews) · a shell or Python script, schema validation or a CI check · the same check runs in Azure Pipelines or GitHub Actions

Rules

  • Scripts read the artefacts, never edit them
  • A failed check blocks; it does not just warn
Done when

At least one task moved from AI to a script, or an AI step now has a check that fails when the step is skipped.

Tips

  • Apply the working agreement “enforce what is deterministic” to your own run. Ask: “Which of these steps did we pay tokens for that a script would do the same way every time?”
  • Typical candidates: renaming and moving files, formatting, counting, schema and front-matter checks, checking that every plan task ID (P01-T01 …) appears in the change log and the review record, and that every acceptance criterion has a test.
  • Where AI stays (research, judgement, synthesis), make it more deterministic: a fixed step list, required output files, a schema for artefacts and a verifier that fails the run when a step is missing.
  • Fill Template 1 across the five phases of the Exercise 5 run: for each, what did we ask the AI to do, could a script do it instead, and which check proves the step happened.
  • Feed the best finding into Exercise 7 (control matrix) and the adoption canvas in Exercise 9.
