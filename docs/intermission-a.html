Intermission A · While Exercise 4 agents run · Open lab 2 · Parallel task

Give the product owner a canvas into the HVE loop

Waiting-time taskOpen lab 2

On this pageBriefHand-in and toolkitTips
Objective

Let a non-developer steer BRD, PRD and ADR generation without writing code.

Input
An approved MCP-capable Copilot workspace, Azure Boards/GitHub context and optional SharePoint/Teams evidence through Work IQ
Best use
Waiting-time task during Ex 4
Roles (suggested)
Product owner leads; agent operator pairs; auditor logs prompts and edits

Steps

  1. Open the workspace in Copilot CLI or a workshop-approved MCP-capable client. Verify approved Azure DevOps/GitHub read tools and optional Work IQ; use fictional excerpts if unavailable.

  2. Ask Copilot to generate a product-owner canvas: goals, users, scope, open questions, decisions.

  3. Read the Azure Boards item or GitHub issue; optionally retrieve approved SharePoint rules and Teams notes through Work IQ, keeping citations. Look up a matching accelerator at accelerators.ms (opens in a new tab).

  4. The PO approves the canvas; Copilot drafts BRD, PRD and ADR, citing sources. The ADR records: adopt, adapt or build.

  5. Tag each statement as sourced, assumed or PO-decided; log every PO correction.

Tips

  • The canvas can be a simple Markdown file or page in the repo that the PO edits in plain language; Copilot regenerates the BRD, PRD and ADR from it.
  • Use approved workshop data and read tools only for source gathering. Work IQ has broader capabilities; keep its update/send actions disabled for this activity.
  • Compare the drafts with the Exercise 4 outputs: what did the PO add that the agents missed?
  • Accelerators are ready-made, maintained solution architectures with deployment guides and costing. Pick the closest match (for example Modernize your Code for a legacy codebase), cite it as the reference architecture in the ADR, and record whether you adopt, adapt or build.
  • If Work IQ or another source connector is unavailable or policy-denied, stop that retrieval and record missing context. Use the approved fictional pack; do not paste private data to bypass a restriction or pretend a live query succeeded.
  • The PO edit log is reused in Exercise 10.
